JavaScript : Interactivité avancée

Maintenant que vous maîtrisez HTML et CSS, nous allons apprendre à rendre vos pages web interactives avec JavaScript. Vous allez voir comment réagir aux actions de l’utilisateur et manipuler le contenu et le style des éléments en temps réel.

1. Réagir aux clics et aux événements

JavaScript permet de détecter les actions de l’utilisateur, comme les clics, les survols ou la saisie clavier. Exemple : afficher un message lorsqu’un bouton est cliqué. 

<button onclick="afficherMessage()">Cliquez ici</button>

<script>
function afficherMessage() {
    alert("Vous avez cliqué !");
}
</script>

2. Modifier le contenu et le style dynamiquement

Vous pouvez changer le texte, les couleurs ou d’autres propriétés d’un élément existant. Par exemple, changer le texte d’un paragraphe lorsqu’un utilisateur clique sur un bouton : 

<p id="demo">Texte initial</p>
<button onclick="changerTexte()">Changer le texte</button>

<script>
function changerTexte() {
    document.getElementById("demo").innerText = "Le texte a changé !";
}
</script>

De la même façon, vous pouvez modifier les styles CSS directement depuis JavaScript : 

<p id="texte">Cliquez pour changer ma couleur</p>
<button onclick="changerCouleur()">Changer la couleur</button>

<script>
function changerCouleur() {
    document.getElementById("texte").style.color = "red";
}
</script>

3. Manipulation avancée du DOM

JavaScript peut ajouter, supprimer ou déplacer des éléments sur la page. Exemple : ajouter un nouvel élément à une liste : 

<ul id="liste">
    <li>Élément 1</li>
</ul>
<button onclick="ajouterElement()">Ajouter un élément</button>

<script>
function ajouterElement() {
    let li = document.createElement("li");
    li.innerText = "Nouvel élément";
    document.getElementById("liste").appendChild(li);
}
</script>
