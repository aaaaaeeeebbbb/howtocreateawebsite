JavaScript

Now that you know HTML and CSS, we will learn how to make your web pages interactive with JavaScript. You will see how to respond to user actions and manipulate content and style in real time.

1. Responding to clicks and events

JavaScript can detect user actions, like clicks, hover, or keyboard input. Example: show a message when a button is clicked. 

<button onclick="showMessage()">Click me</button>

<script>
function showMessage() {
    alert("You clicked the button!");
}
</script>

2. Changing content and styles dynamically

You can change the text, color, or other properties of an element. For example, change a paragraph’s text when the user clicks a button: 

<p id="demo">Initial text</p>
<button onclick="changeText()">Change text</button>

<script>
function changeText() {
    document.getElementById("demo").innerText = "The text has changed!";
}
</script>

Similarly, you can modify CSS styles directly from JavaScript: 

<p id="text">Click to change my color</p>
<button onclick="changeColor()">Change color</button>

<script>
function changeColor() {
    document.getElementById("text").style.color = "red";
}
</script>

3. Advanced DOM manipulation

JavaScript can add, remove, or move elements on the page. Example: add a new item to a list: 

<ul id="list">
    <li>Item 1</li>
</ul>
<button onclick="addItem()">Add item</button>

<script>
function addItem() {
    let li = document.createElement("li");
    li.innerText = "New item";
    document.getElementById("list").appendChild(li);
}
</script>
